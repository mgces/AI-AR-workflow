# OpenHarmony 源码导航

知识库已降级为稳定导航层：它帮助定位候选子系统、组件、进程、能力和 feature，但不提供当前代码事实。

## 关键边界

- 导航可以回答“从哪里开始找”。
- 当前源码回答“文件、接口、target、依赖、配置和行为现在是什么”。
- 构建、测试、真机和 CI 证据回答“当前实现是否真的成立”。

知识库与源码不一致时，以当前源码和真实验证证据为准。
