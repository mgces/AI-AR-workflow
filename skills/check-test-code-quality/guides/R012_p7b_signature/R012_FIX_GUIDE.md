# R012 p7b 签名问题处理

R012 用于识别 profile 的 APL、app-feature 与权限约束问题。签名材料属于用户或组织的受控资产，本 skill 只提供检查和处理流程，不捆绑 JAR、私钥、证书、profile、固定密码或已签名样例。

## 安全边界

- 从组织批准的渠道取得 `hap-sign-tool.jar`、keystore、证书链和 profile 模板，并在执行前核验版本或摘要。
- 所有凭据只放在用户控制的外部临时目录；不得复制到本 skill、目标源码仓或扫描报告。
- 不在命令行、日志、PR 或 Agent 对话中展开密码。优先使用组织提供的安全输入机制。
- 修改前备份目标 profile；输出文件先写到外部临时目录，验证成功后再替换明确的目标文件。

## 处理流程

1. 用受信工具读取原 profile，确认 bundle-info、APL、app-feature、ACL 和允许权限。
2. 根据目标 XTS 工程的实际权限需求修正模板；未知权限或企业权限必须交由对应安全/签名 Owner 确认，Agent 不自行放宽。
3. 使用组织批准的签名命令和凭据生成新的 p7b。命令参数以该工具版本的官方帮助和组织规范为准，不复用本 skill 中的示例路径或口令。
4. 校验新文件可解析、签名链有效、bundle-name/权限未发生非预期变化。
5. 只替换用户明确指定的 p7b，再运行 R012 扫描和目标 XTS 测试；任一步失败都保留原文件并报告失败。

## 失败关闭

缺少批准的签名工具、凭据、Owner 结论或验证环境时，只输出问题和所需输入，不下载工具、不生成假证书、不把未签名结果标记为修复成功。
